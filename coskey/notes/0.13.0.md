Coskey 0.13.0 — 按你的习惯启动 ChatGPT.app

- 新增「个性化」页，可以调整 ChatGPT.app 的界面语言、左侧导航、应用快照、
  电脑操控等能力。每项都会显示默认值、当前值和来源，也能随时恢复默认
- 新增「ChatGPT 个性化启动器」：macOS 生成启动 App，Windows 生成桌面快捷方式。
  双击即可按你的设置启动 ChatGPT.app；如果它正在运行，会先退出再重新打开。
  从 Dock、Finder 或开始菜单直接启动不会带上个性化设置
- 个性化只适用于 ChatGPT.app 的 API key 模式。设置只保存在本机，不会上传账号信息，
  也不会修改系统代理或根证书；它不会获得额外的账号、套餐或地区权限。相关功能能否使用，
  仍取决于插件、系统权限和 ChatGPT.app 自身的条件
- 修改后通过 coskey 重新启动 ChatGPT.app 才会生效。切换默认来源时，
  「采用为新基线」会保留已有修改；「重新生成」会清空全部单项修改，操作前会先预览并再次确认
- 状态页的 ChatGPT.app 区域改为只读检查，配置入口集中到「个性化」页。旧的
  `coskey app repair` 和 `app statsig seed` 写入口已停用，终端用户改用
  `coskey app egress` 命令
- API key 登录项里的中转名称未手动设置时，会跟随 Codex 当前 provider 的展示名；
  读不到才显示 `coskey local relay`。同时修复 macOS 运行实例识别，并精简设置页和插件页入口

建议所有 0.12.0 用户升级。
