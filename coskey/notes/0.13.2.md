Coskey 0.13.2 — 修复个性化后 ChatGPT 的“连接”设置入口消失

- 修复开启 ChatGPT.app 个性化后，“设置 → 连接”入口不再显示的问题
- 个性化默认值投影新增 gate `4114442250`；macOS 与 Windows 使用同一修复，不需要额外的平台适配
- 该修复只恢复“连接”设置入口，不会额外开放 SSH、WSL 或远程控制能力；这些功能仍取决于
  ChatGPT.app 自身的配置、gate 和本机服务状态
- 如果此前已经保存过个性化设置，内置默认值的校验值会随新增 gate 改变。请先在「个性化」
  页采用新的内置基线（保留兼容修改）或从内置重新生成，再通过 Coskey 重启 ChatGPT.app；
  旧配置不会被静默换用
- 已有的个性化代理实例不会自动刷新 Statsig 值，必须重新启动 ChatGPT.app

建议所有在 API key 模式下使用个性化、且设置中缺少“连接”入口的用户升级。
