Coskey 0.7.1 — 同名模型不再走错通路，配置更耐版本切换

- 修同名模型走错通路：用 API key 登录 ChatGPT.app 时，与官方目录同名的模型不再被
  当成官方请求发出去后失败；现在按本机「有没有真正的 ChatGPT 登录态」判断，没登录
  就照常走你配的映射（设置页「与官方目录同名的优先级」为 auto 时生效）
- 配置不怕版本来回切：coskey 读配置时不再顺手改写文件，遇到当前版本不认识的写法
  也只按默认值处理并记一条日志，不再直接报「解析 coskey.toml 失败」打不开。要退回
  0.6.0 的话，先把 coskey.toml 里 on_official_model 那行写回旧写法（unified 改回
  redirect、separate 改回 passthrough，语义不变），否则 0.6.0 不认它
- Windows 安装包补上身份与语言：安装界面支持简体中文和英文（跟随系统语言），
  「设置 → 应用」里的发布者显示为 cosk；升级安装继续沿用你上次的安装位置，
  不会多装一份
