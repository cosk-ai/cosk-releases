Coskey 0.2.0 — 供应商与模型管理改进

- 首次引导只保留「安装包装器与启动配置」一步：装完直接进主界面，供应商、
  模型改为进界面后按需添加，不再强制在引导里一口气录完
- 供应商页新增 Base URL 测速：一键测你所填地址是否可达、要多久；「测试连接」
  也会显示耗时，连接结论更直观
- 模型列表支持展示名 / 应用模型 ID 一键切换（T / # 图标）；「映射到」改为
  「被谁使用」，明确该模型在 ChatGPT.app 模型列表里出现的名字
- 导入模型支持搜索、清空搜索、按当前搜索结果全选；上游模型多时不用再翻长列表
- 会话列表标题改为单行省略，鼠标悬停显示完整标题
- 会话项目分组对齐 ChatGPT.app：按 app 里的显式项目归属分组；无显式归属时按
  目录推断，无法唯一确定时归入「其它」，与左侧栏观感一致
- Windows 安装包随本版同步更新（未签名预览，仅供本机体验）
