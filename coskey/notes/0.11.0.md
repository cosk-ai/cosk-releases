Coskey 0.11.0 — 把 coskey 的模型分享给其它 Agent，并在终端里直接用

- 新增「模型网关」页：把 coskey 里已经配好的模型开放成一个固定地址，本机或同一局域网的
  Codex、IDE、脚本都能直接用，不必再重复填写供应商密钥。每个客户端有独立 token，
  可随时轮换或撤销
- 每个客户端可以单独挑模型：第三方模型和官方模型放在同一份清单里，选谁就只给谁用。
  官方模型走你本机的 ChatGPT 登录态，客户端拿不到你的账号凭据
- 新增「远端通道」页：给远程服务器上的 Codex 配置模型，两种方式任选——经本机网关中转，
  或把某个供应商直连写进远端。两种方式都先给出计划，确认后才动远端配置。通道可手动启停，
  也能设成随 ChatGPT 启动或停止
- macOS 和 Windows 都可以建立远端通道；Windows 使用系统 OpenSSH 在后台运行隧道，
  不会弹出控制台窗口。远端目标支持 Linux 和 macOS
- 远端对话能直接选 coskey 模型：在 ChatGPT 里连上那台服务器并打开远端目录后，
  对话框的模型选择器就会列出你授权的模型。远端不需要装 coskey
- 新增 `coskey codex`：用官方 Codex CLI 直接跑 coskey 的模型，支持交互、`exec` 和
  `resume`。会话里用 `/model` 就能切换，跨供应商也不用重开；选完模型按 Enter 会写入
  Codex 默认配置，按 `s` 只影响当前会话
- 安装后自动提供 `coskey` 命令行入口，新开终端即可使用。关闭 Coskey 窗口只会缩到托盘，
  网关和远端通道继续工作
- 修复升级 ChatGPT.app 后可能提示「组织设置无法加载」：不再误用与当前 app 不匹配的内核，
  启动检查失败时会自动改用 app 自带的内核。macOS 和 Windows 均已适配

详细步骤与截图可在 Coskey 帮助文档中查看。
