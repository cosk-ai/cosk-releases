Coskey 0.7.4 — 认不出的模型名不再弄丢会话，模型目录开箱可用

- 修「认不出的模型名让会话脱离 coskey 接管」：以前这类请求原样发给内核自己的通路，
  之后同一条会话里改选第三方模型会直接报错。现在一律经 coskey，由中继回一条看得懂
  的 404 提示你改选；想让它自动改用默认模型，把设置页「认不出的模型名」改成 default
- 「默认模型」只管新会话：新建或克隆会话没带模型时选上它，跟随全局切换、不钉住
- 首次安装就把模型目录备齐（模板 + 缓存），模型映射页可直接按模板设窗口；先装
  coskey、后装 ChatGPT.app 也行，重开 app 会自动补上官方模型
- Windows 上复制 API key 不再闪一下黑窗
