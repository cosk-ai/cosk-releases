Coskey 0.13.1 — 修复新版 ChatGPT.app 下浏览器和电脑操控不可用

- 适配 ChatGPT.app 26.1103 及以上版本的 macOS 安全校验：修复模型对话正常，
  但浏览器、Chrome / Edge 控制或电脑操控相关工具无法连接的问题
- 修复浏览器工具可能误用 coskey 包装器作为 Codex 内核的问题。现在会固定使用
  ChatGPT.app 自带的 Codex，macOS 和 Windows 同步生效
- 升级后请完全退出并重新启动 ChatGPT.app。只重启浏览器或重装扩展不会刷新已经启动的内核
- 如果 ChatGPT.app 自带的 Codex 版本较旧，聊天仍会正常工作，但浏览器控制会暂时不可用。
  请升级 ChatGPT.app；「体检」会明确提示原因

建议所有 0.13.0 用户升级，尤其是使用新版 ChatGPT.app 的 macOS 用户。
