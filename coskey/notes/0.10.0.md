Coskey 0.10.0 — 新增插件市场，常用管理可以交给 Coskey Tools

- 新增「插件」页：查看插件市场、版本、来源、技能和 MCP 能力，以及是否已安装、
  已启用；可以刷新市场、诊断、回滚，也能直接打开帮助文档。macOS 和 Windows
  都可用
- 插件市场先带 Coskey Tools：安装并在 ChatGPT.app 启用后，可以直接查询 coskey
  状态、切换模型、查看、接管、转交会话，或排查连接问题。安装和启用仍在
  ChatGPT.app 的插件页完成，Coskey 不会替你操作
- 插件来源更灵活：可以从 Coskey 远端目录下载更新，也可以导入本地插件 ZIP。
  打开插件页会自动检查版本，断网时继续使用上次缓存；下载失败会保留旧版本。
  导入只会加入本地市场，之后仍需到 ChatGPT.app 安装
- 下载和运行都有保护：插件包会校验大小与 SHA-256，并拒绝危险路径和符号链接；
  本地 MCP 只调用固定的 coskey 工具，不提供任意 shell、文件或网络访问。
  切换模型、接管、转交和修复前都会先说明影响并等待确认
- 匿名装机标识改为单独保存在「~/.coskey/.install_id」：普通卸载和 --purge
  都会保留，重装后继续使用；想重置时手动删除这个文件即可
