Coskey 0.12.0 — 适配新版 ChatGPT，会话和网关更省心

- 修复升级到新版 ChatGPT.app 后，已有 coskey 会话发送消息可能被拒绝的问题。
  新建会话、连续对话和重启后重新打开都已适配
- 官方模型现在固定经 coskey 中转，不再需要选择“统一 / 分开”策略。官方和第三方模型
  可以在同一会话里自由切换，旧配置会自动兼容，不需要手动清理
- 设置页可以修改 ChatGPT.app 左下角 API key 登录项里显示的中转名称，留空恢复默认名称。
  这里只改显示文字，不影响内部配置；重启 ChatGPT.app 后生效
- 修复旧会话被 ChatGPT.app 自动压缩后，被误判为“会话文件缺失”的问题。这些会话仍可
  正常打开，并会显示“已压缩”标记
- Coskey Tools 更新到 0.3.3：在 ChatGPT.app 里可以查询模型网关状态、已授权的接入程序和
  可用模型；远端 Codex 接入支持选择多个模型，也可以复用已有接入程序。已安装旧版的用户
  可按插件页提示更新
- 「转交」仍是卸载前的正式迁移入口：先退出 ChatGPT.app，再把历史会话交给原生或其它
  已配置的模型来源

建议所有 0.11.0 用户升级。
