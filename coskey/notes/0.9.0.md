Coskey 0.9.0 — 一键修复 ChatGPT.app 的 Browser、中文界面和电脑操控

- 状态页新增「ChatGPT.app」检测：分别检查 Browser 插件、浏览器扩展连接、中文界面、
  电脑操控，以及这些功能依赖的七项能力值；两小时内复用结果，也可随时「重新检测」。命令行可用
  `coskey app check` 查看同样的问题，用 `coskey app repair --id <检查项>` 修复单项
- Browser 开关置灰、选了中文仍显示英文，或找不到「电脑操控 → 任意应用」时，可以点
  「一键修复」：先列出要改的内容并确认，再退出 ChatGPT.app、按需补齐插件配置并写入
  离线能力，完成后重启 ChatGPT.app 即可生效
- macOS 和 Windows 均已适配。离线能力写入适用于 API key / 无会话场景；不会修改
  ChatGPT.app 安装包、账号文件或站点策略，也不会替你安装插件或开启系统权限
- 修复提示更清楚：确认框会说明需要退出正在进行的会话，打开 ChatGPT.app 时会显示
  「正在打开」，不会让人误以为按钮没反应
