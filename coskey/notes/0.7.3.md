Coskey 0.7.3 — 系统目录操作更顺手，没登录官方也能在同一会话里换模型

- 修「用 API key 登录时，同一条会话里换不了第三方模型」：这类机器上没有 ChatGPT 登录态，
  以前用官方模型名开的新会话不会被 coskey 接管，模型来源在建会话时就固定住了，之后在同一
  会话里改选第三方模型会直接报错。现在官方模型名一律照常接管（默认的 unified 档）：没登录
  时 coskey 会明确告诉你「未登录 ChatGPT」，并提示你直接在这条会话里改选第三方模型即可，
  不用新开会话
- 系统目录（官方模型在 ChatGPT.app 里的形态）操作更直观：表格里的「展示」「启用」改成
  只读状态列，两件事都收进操作列的图标动作，图标按动作取形（眼睛 = 展示 / 不展示，
  电源 = 启用 / 停用），与模型映射页同一套口径
- 「编辑」改成弹窗：默认窗口、窗口上限、展示、启用一次保存，不再分两处改
- 新增三个批量动作（与「重新生成系统目录」同一行）：批量不展示、批量停用、批量恢复
  官方配置——整批一次完成、只重新合并一次缓存，不会做到一半留下半套状态；当前没事可做
  的那枚按钮会置灰
