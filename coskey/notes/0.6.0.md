Coskey 0.6.0 — 模型目录更好用，改动即时生效

- 「模型目录」页三个页签改名：用户目录、系统目录、目录模板。目录模板现在能
  检查并安装新版本、装回旧版本或删掉不用的；下载走设置页新加的「下载镜像」，
  可选自动 / GitHub / Gitee，拿不准还能测速
- 内置 DeepSeek、千问、GLM、Kimi、MiniMax 等常用目录模板：装好就有一份现成
  的目录，不用自己一个个建；每个模板还能一键生成对应目录，模板更新时跟着更新
- 不需要的可以单独关掉：官方模型能不让它出现在 ChatGPT.app 的模型列表里；
  自己建的模型也能临时停用，设置原样保留，随时开回来
- 「模型映射」和「供应商」页更顺手：映射每行默认显示它在 ChatGPT.app 里的
  名字，点开还能看到用了哪份目录；供应商可以拖动排序，也能直接给某个模型建映射
- 改动即时生效：加供应商、加模型、加映射或停用，都不用再重启 ChatGPT.app，
  下一条消息就用新配置（列表最迟约 5 分钟刷新，重启更快；改用户目录仍需重启）
- 更新应用后包装器会自动升到同一版本，不用再手动装一次；映射指向的模型不在
  目录里时，打开会话也不再报错，把模型加回目录就好
