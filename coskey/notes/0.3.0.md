Coskey 0.3.0 — 官网更新入口与匿名装机统计

- 更新检查优先走 cosk.ai 官网，取不到时自动回退 GitHub / Gitee；下载、安装与
  重启流程都不变
- 为了让开发者知道大概有多少设备在用，首次检查更新时会在这台机器上生成一个
  随机编号，之后每次检查更新都带上它，用于按天统计设备数量和各版本的使用
  情况；编号不含账号、设备型号、用户名，也与你的 API key、供应商配置和
  对话内容无关
- 不想要这个编号时，删掉 `~/.coskey/state.json` 里的 `install_id` 即可，之后
  会被当成一台新设备；更新检查、下载与安装都不受影响。目前没有关闭统计的
  开关，所以这里不承诺「可以关闭」
- 用户协议与隐私政策升到 v1.2，如实说明上面这项统计：对话内容、代码、文件与
  API key 仍然一概不上传
