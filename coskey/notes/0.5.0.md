Coskey 0.5.0 — 供应商页更省事，模型探测更准

- 新增供应商支持一键填充：表单顶部列出 DeepSeek、千问、智谱、Kimi、MiniMax，
  点一下就把名称和地址填好，只差 API key；末尾「更多…」还能拉一份最新供应商清单
- 供应商页更好用：可按供应商快速跳转与高亮，卡片上能一键复制端点与 API key，
  标题前面还会按地址自动显示对应供应商的图标
- 模型探测更准：修了图像等能力被探错的问题；「测试连接」给出不思考与带思考
  两个耗时；每个模型还能单独「探测协议」，结论就显示在那一行下面。用不到的
  「音频」勾选已撤掉
- 修 ChatGPT.app 升级后 coskey 失效：新版 app 换了内核位置，现在会自动找到，
  升级后不再卡在启动页、报与真实原因无关的「组织设置无法加载」
- 修自建供应商的会话被错当成官方：这类会话里改选模型不再报错
