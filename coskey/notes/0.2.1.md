Coskey 0.2.1 — 会话不中断与更新体验

- 改模型映射不再打断正在用的会话：以前改配置会让本地中转重启、端口变化，
  指向旧端口的会话会报「未配置的模型」或连接失败；现在中转原地更换路由表，
  端口与连接保持不变，改完即刻生效
- 更新检查与下载进度收进一个对话框：设置页「检查更新」、菜单「检查更新…」
  与「立即更新」共用同一个窗口，检查中、下载中（进度与百分比）、安装中都在
  窗里完成，不再整屏接管应用界面
- Windows 端不再误报更新：清单先发 macOS、Windows 包稍后补的窗口期里，
  不会再提示一个本平台装不上的新版本，也不会出现关不掉的强制更新弹窗
- Windows 上会话的项目归属修好了：没有显式项目归属的会话此前一律落进「其它」，
  现在按所在目录归入对应项目，子目录里的会话也能归对
- 修删除供应商报错；删除供应商或模型时，明确告知连带删除的选择器条目与
  已清除的会话钉住
- 「打开报错」的历史会话适配与卸载不再被残留写锁拦住（app 已退出时也放行），
  体检里也不再列写锁项
- 模型探测更准：上游对输出上限有下限校验（如要求 ≥16）时不再误判为
  「无法判定」，探测失败也直接显示上游给出的原因
- 添加上游模型时，窗口大小输入框的提示值改为 1000000
- 用户协议与隐私政策升 v1.1：平台描述覆盖 Windows，条款实质未变
