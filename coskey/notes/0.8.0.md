Coskey 0.8.0 — 打开会话不再被全局模型顶掉，会话页更好懂

- 修「点开一下会话，模型就被换成全局模型」：现在打开已适配的会话，用的就是这条
  会话自己的模型——有钉住用钉住值，没钉住跟随全局
- 会话页一眼看懂「这条会话归谁管」：已适配的首行直接写 coskey，内核里的旧值降为
  下面一行小字；已适配的会话不再挂「provider 不可解析」红标
- 本地 / 云内置来源的会话不再被误判成「打开报错」，想交给 coskey 管时也能正常适配
- 会话页用词与交互收口：适配 / 原生 / 可转交·已转交 一套词，命令行同一口径；
  徽标最多显示两枚，行内按钮改图标（归档的会变灰并说明原因），分页条上下各一条，
  批量操作区移到右下角
