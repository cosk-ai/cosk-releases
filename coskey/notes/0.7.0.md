Coskey 0.7.0 — 官方模型与第三方模型可在同一会话里互切

- 官方模型现在也走 coskey 转发（新增默认策略）：在 ChatGPT.app 里选官方模型，请求由
  coskey 送到官方后端，消耗的是你的 ChatGPT 订阅额度，不会被悄悄换成某个第三方
  模型。好处是同一条会话里官方模型和第三方模型可以随时互切，不用再新开会话
- 官方模型策略只剩两档，设置页可选：unified（默认，官方经 coskey 转发，同会话可
  互切）/ separate（官方走内核原生 OpenAI、完全不经过 coskey，与第三方是两条
  独立通路，换来源要开新会话）。旧配置里的 redirect / passthrough 升级时自动
  转换，不用手工改
- 设置页新增「与官方目录同名的优先级」：有些供应商用的模型名和官方一样，这时由
  你决定谁赢得这个名字——auto（默认，官方链路可用时官方优先，否则用你的映射）、
  official（官方条目接管）、coskey（应用模型接管并显示自己的名字）
- 本机没登录 ChatGPT 时，选官方模型不再被悄悄换成第三方模型：请求原样交给官方通路，
  由官方提示登录
- 修模型名解析：在选择器里回传的模型按应用模型 id 精确匹配，没配置过的名字会明确
  报错，不再被静默改道到别的模型
